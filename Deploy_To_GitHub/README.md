# ប្រព័ន្ធគ្រប់គ្រងបូកស្រង់ពិន្ទុប្រឡងជ្រើសរើស ក.ច.ប (PEC21 - ខេត្តតាកែវ)
### ដំណើរការទាំង Offline (កុំព្យូទ័រទោល/LAN) និង Online

ប្រព័ន្ធនេះត្រូវបានរចនាឡើងយ៉ាងពិសេសសម្រាប់ **គណៈកម្មការរៀបចំការបោះឆ្នោតខេត្តតាកែវ (គ.ខ.ប ២១)** និង **គ្រូបង្គោលប្រចាំក្រុង/ស្រុកទាំង ១០** ដើម្បីបូកស្រង់ គ្រប់គ្រង និងចេញតារាងលទ្ធផលប្រឡងជ្រើសរើសសមាសភាពក្រុមចុះឈ្មោះបោះឆ្នោត (ក.ច.ប) ឆ្នាំ២០២៦ យ៉ាងរហ័ស ត្រឹមត្រូវ និងរលូនបំផុត (Smooth)។

## ១. របៀបដំណើរការប្រព័ន្ធ (How to Run)

### វិធីទី១៖ ដំណើរការដោយចុចពីរដង (ងាយស្រួលបំផុត)
* ចូលទៅកាន់ថត `D:\I_ការងារបោះឆ្នោត\កម្មវិធីបូកស្រង់នៃការប្រឡង\Web_App_កចប_2026`
* ចុចពីរដង (Double Click) លើឯកសារ **`Start_App.bat`**
* ប្រព័ន្ធនឹងបើក Web Browser ដោយស្វ័យប្រវត្តិតាមអាសយដ្ឋាន `http://localhost:3000`

### វិធីទី២៖ ដំណើរការតាម Command Line
```bash
cd "D:\I_ការងារបោះឆ្នោត\កម្មវិធីបូកស្រង់នៃការប្រឡង\Web_App_កចប_2026"
node server.js
```

## ២. របៀបប្រើប្រាស់ Offline និង Online ពីចម្ងាយ (Remote Online)

### ក. ដំណើរការ Offline (កុំព្យូទ័រទោល ឬបណ្តាញ LAN ក្នុងលេខាធិការដ្ឋាន)
* ចុចពីរដងលើ **`Start_App.bat`**
* ប្រព័ន្ធដំណើរការបាន ១០០% ដោយគ្មានអ៊ីនធឺណិត (Zero External CDN Dependency) តាមរយៈ `http://localhost:3000` ឬតាម IP LAN ក្នុងបន្ទប់តែមួយ (ឧ. `http://192.168.1.15:3000`)។

### ខ. ដំណើរការ Online ពីចម្ងាយដោយមិនបាច់ប្រើ Wi-Fi តែមួយ (Remote Online for 10 Districts)
* ចុចពីរដងលើ **`Start_Online_Public.bat`**
* ប្រព័ន្ធនឹងបង្កើតតំណភ្ជាប់ Online សាធារណៈដែលមានសុវត្ថិភាពខ្ពស់ (Cloudflare HTTPS Tunnel) ដោយស្វ័យប្រវត្តិនូវ Link ដូចជា៖
  `https://xxxxxx.trycloudflare.com`
* លោកអ្នកគ្រាន់តែ **Copy Link នេះផ្ញើជូនគ្រូប្រចាំក្រុង/ស្រុកទាំង ១០ តាម Telegram** នោះពួកគាត់អាចប្រើទូរស័ព្ទ, iPad ឬកុំព្យូទ័រភ្ជាប់ 4G/5G/Wi-Fi នៅតាមស្រុកនានា ដើម្បីចូលប្រព័ន្ធ និងបញ្ចូលឈ្មោះបេក្ខជនពីចម្ងាយបានភ្លាមៗ!

## ៣. មុខងារថ្មីពិសេស៖ Tab «លេខកូដ» & ស្វ័យប្រវត្តិចេញពិន្ទុ QCM (Secret Code Workflow)
1. **ផ្ទាំង «លេខកូដ» (Codes Management):**
   * ផ្ទុកបញ្ជីលេខកូដសម្ងាត់ទាំងអស់ (៣១៧ កូដស្រង់ចេញពី Excel) ជាមួយពិន្ទុ QCM របស់កូដនីមួយៗ (ឧ. `AB001` -> `44.00`)។
   * អាចកែសម្រួលពិន្ទុ QCM ដោយផ្ទាល់លើតារាងលេខកូដ ឬបន្ថែមលេខកូដថ្មីបានគ្រប់ពេល។
   * មានប៊ូតុង **«បិទភ្ជាប់ពី Excel (Paste from Excel)»** ដើម្បីចម្លងទិន្នន័យកូដ និងពិន្ទុពី Excel ចូលជាដុំយ៉ាងងាយស្រួល។
2. **ការតភ្ជាប់ពិន្ទុដោយស្វ័យប្រវត្តិនឹងបេក្ខជន (Instant Auto-fill):**
   * នៅលើតារាងបេក្ខជន (Tab បញ្ចូល & កែសម្រួលពិន្ទុ) លោកអ្នកគ្រាន់តែ **ជ្រើសរើស ឬវាយលេខកូដ (ឧ. `AB001`)** នៅជួរឈរកូដពីមុខឈ្មោះបេក្ខជន។
   * ប្រព័ន្ធនឹង **ទាញយកពិន្ទុ QCM តាមលេខកូដនោះមកបំពេញជូនភ្លាមៗ (Instant Auto-fill)** រួចបូកសរុបពិន្ទុ គណនាចំណាត់ថ្នាក់ និងចេញលទ្ធផល (`A-ជាប់`, `B-បម្រុង`, `ធ្លាក់`) ដោយស្វ័យប្រវត្តិ។

## ៥. មុខងារសំខាន់ៗរបស់ប្រព័ន្ធ (Key Features)

1. **ផ្ទាំងគ្រប់គ្រង (Dashboard):** ស្ថិតិបេក្ខជនសរុប ៤១៧ នាក់, ចំនួនស្រី, ជាប់ស្ថាពរ, បម្រុង, ធ្លាក់, អវត្តមាន និងតារាងវឌ្ឍនភាពតាមស្រុកនីមួយៗ។
2. **ផ្ទាំងលេខកូដ (Secret Codes & QCM):** គ្រប់គ្រងកូដសម្ងាត់ តាមដានកូដដែលបានភ្ជាប់បេក្ខជន និងកូដនៅទំនេរ។
3. **បញ្ចូល និងកែសម្រួលពិន្ទុ (Score Entry):** បញ្ចូលពិន្ទុ ឬលេខកូដផ្ទាល់លើតារាង (Inline editing) ដំណើរការរលូនឥតទាក់ (Smooth)។
4. **តារាងស្រង់ពិន្ទុផ្លូវការ (Official Tabulation Sheet):** ទម្រង់បែបបទស្របតាមស្តង់ដារ គ.ជ.ប មានក្បាលលិខិតជាតិ និងប្រអប់ហត្ថលេខា សម្រាប់បោះពុម្ពទំហំ A4 Landscape យ៉ាងស្រស់ស្អាត។
5. **តារាងលទ្ធផលប្រឡង (Official Results):** បង្ហាញលទ្ធផលផ្លូវការតាមឃុំ និងមុខតំណែង ត្រៀមជាស្រេចសម្រាប់បោះពុម្ពផ្សាយ។
6. **បញ្ជីសមាសភាព ក.ច.ប (Final 343 Roster):** បញ្ជីរាយនាមសមាសភាពផ្លូវការទាំង ៣៤៣ រូបទូទាំង ១០០ ឃុំ/សង្កាត់ នៃខេត្តតាកែវ។
7. **ការបម្រុងទុក (Backup & Restore):** អាចទាញយកឯកសារបម្រុងទុក (JSON) ឬនាំចេញជា Excel/CSV បានគ្រប់ពេល។
